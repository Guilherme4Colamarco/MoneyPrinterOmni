# MAP: MoneyPrinterOmni in one file

Compact map for agents and contributors. Detail, examples and practice: the vault in [`en/`](en/00%20-%20Index.md). Facts were checked against the code; `file:line` can age, so confirm with `grep -n`. Português: [`MAPA.md`](MAPA.md).

## 1. The program
Three entry points reach the same function: `app/services/task.py::start()` → `_run_pipeline`.

| Entry point | File | How it reaches `start()` |
|---|---|---|
| API (FastAPI, `:8080`) | `main.py` → `app/asgi.py`, routes in `app/controllers/v1/` | `task_manager.add_task(tm.start, …)` (queued; 429 when full) |
| WebUI (Streamlit, `:8501`) | `webui/Main.py`, `app/services/webui_task.py` | `submit_generation()` holding `runtime_config_lock` |
| CLI | `cli.py` (`mpt cli`) | direct and synchronous, `allow_server_file_input=True`; JSON on stdout, exit 0/1/2 |

Stages (`stop_at` cuts after any of them): **script** (`llm.generate_script`) → **terms** (`llm.generate_terms`) → **audio** (`voice.tts`) → **subtitle** (`edge` or `whisper`) → **materials** (`material.download_videos`, `local`, `loomloom`) → **video** (`video.combine_videos` → `generate_video`, optional BGM) → cross-post (`upload_post`, after completion). Audio comes BEFORE subtitles. Files in `storage/tasks/<id>/`: `script.json`, `audio.mp3`, `subtitle.srt`, `combined-N.mp4`, `final-N.mp4`. State: `app/services/state.py` (memory or Redis).

Gotchas: `video_project.py` is OUTSIDE the pipeline (run with `python -m`); `runtime_config_lock` is only taken by the WebUI; `allow_server_file_input` is CLI-only; resources go through `app/paths.py`.

Config: `config.toml` (from `config.example.toml`), `app/config/config.py`. LLM providers: registry `LLM_PROVIDER_REGISTRY` in `app/models/llm_provider.py` (37), adapters in `app/services/llm.py`; subscription-based: `claude_code` (official CLI) and `kimi_code` (OAuth). Music: `_VIDEO_MUSIC_PROVIDERS` in `task.py`.

## 2. The agent harness
Single source of truth: `AGENTS.md` + `.agents/`. Adapters only point there.

| Layer | Where | What for |
|---|---|---|
| Rules | `.agents/setup.md`, `.agents/tecnico.md`, `.agents/pipeline.md`, `.agents/comunicacao.md` | priority: request > brief > profile > tastes > setup |
| Roles | `.agents/roles/*.md` (20) | one per function; the model lives only in the adapters |
| Skills | `.agents/skills/video/` (13 steps, scripts in `scripts/`), `.agents/skills/manutencao/` | orchestration |
| Playbooks and profiles | `.agents/playbooks/`, `.agents/perfis/` | recipes (yt-dlp, social media, ffmpeg, MPT) and one profile per channel |
| Adapters | `.claude/agents/`, `.claude/skills/`, `.grok/agents/` and `.grok/personas/` (generated by `.agents/tools/sync_grok_agents.py`) | Claude Code and Grok Build |
| MCP | `.mcp.json`, `.claude/settings.json`, `.claude/hooks/ensure-yt-dlp.sh` | yt-dlp (main); reddit and apify (unstable); read-only |

Video team (12 roles, folder `storage/projects/<slug>/`): pesquisador → (critico, sugestor-de-pauta, auditor) → diretor-de-arte → **diretor (approval stop)** → montador-mpt (audio, `timing.json`) → cacador-de-clipes → animador → editor-de-clipes → montador-mpt (render) → critico + auditor → designer-de-thumbnail + redator-de-publicacao → diretor (delivery). It never publishes. Technical team (8 roles, `storage/manutencao/<slug>/`): arquiteto, desenvolvedor, testador, revisor-de-codigo, auditor-de-seguranca, auditor-de-saude, pesquisador-de-integracoes, mantenedor-do-harness.

## 3. Origin and branches
Fork of MoneyPrinterTurbo at commit `9e7d8b7`; rebrand `a6c685c` (`app/paths.py:_with_legacy` keeps the old data folder). On 2026-10-22 upstream v1.3.9 was merged in. Remote `upstream` = `harry0703/MoneyPrinterTurbo`.
- **`main`**: only what is tested and proven (stock video sources, AI scripts, the agent flow, Remotion, yt-dlp, the Grok adapter).
- **`unstable`**: recently added and little tested (Reddit/Apify MCPs, technical team, new animations, upstream v1.3.9, future subscriptions). Promoted to `main` by PR once fixed and tested. No force-push.

## 4. Commands
```sh
nix develop --command uv sync --frozen            # environment (the Nix ffmpeg passes the audio tests)
nix develop --command uv run ruff check app cli.py main.py webui test docs/skill
nix develop --command uv run python -X utf8 -m pytest -q test
nix develop --command bash -c 'uv run python -X utf8 -m coverage run -m pytest -q test && uv run python -m coverage report'   # fail_under = 70
python3 -m docs.mapa.tools.check_vault     # checks this guide
```
Service layer first (all three entry points inherit it); new WebUI text in every `webui/i18n/*.json`; dependencies only through `uv`.

## 5. Known issues (found while writing the guide)
Security: `GET /api/v1/tasks/{id}` returns an absolute server path in `materials`; `listen_host = "0.0.0.0"` with an empty `api_key` is the default. Others: `version_checker.py` queries Turbo's releases; the `Dockerfile` still installs `requirements.txt`; `build_timeline.py` calls yt-dlp through Nix; old comments are still in Chinese. See the "Pitfalls" sections of the notes.
